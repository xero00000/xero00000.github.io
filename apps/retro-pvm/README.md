# CRT Lab Pro 3

A self-contained WebGL2 CRT and analog-video laboratory for the Xero Web Lab GitHub Pages site.

## Major systems

- Two-pass GPU pipeline with simultaneous raw and processed render targets for movable A/B comparison.
- RGB, YPbPr, S-Video, NTSC composite, PAL composite, RF and VHS signal paths.
- Analog bandwidth, chroma delay/bleed, comb filters, dot crawl, edge ringing, multipath, sync faults, AGC/hum, VHS tracking and dropout.
- Frame-rate-independent per-channel phosphor decay, beam scan/width/bloom, focus, halation, aperture grille/shadow/slot/PC masks, scanlines and interlace.
- Service geometry, convergence, overscan, pincushion, trapezoid, corner pin, linearity, tube aging, burn-in and gun faults.
- Twelve built-in calibration/test patterns and a guided seven-step calibration workflow.
- Live luma waveform, vectorscope and histogram with IRE/chroma measurements.
- Image/video drag-drop and paste, camera input, display capture, source framing, freeze and frame stepping.
- PNG capture, clipboard/share-frame actions and processed WebM/MP4 recording when supported by the browser.
- Built-in profiles, local user profiles, undo/redo, JSON import/export, fault bursts and shareable exact-calibration URLs.
- Adaptive render quality, GPU diagnostics, context-loss recovery, local persistence and installable/offline PWA support.

The app has no third-party runtime dependencies.
